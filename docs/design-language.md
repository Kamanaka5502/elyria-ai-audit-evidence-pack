# Design Language

## Purpose

This document defines the public-facing visual and language system for the Elyria AI Audit Evidence Pack.

The goal is premium enterprise presentation: executive-readable, technically credible, audit-oriented, and public-safe.

---

## Visual Positioning

```text
Governance proof
Audit evidence
Replay readiness
Decision record
Evidence packet
Proof preservation
```

---

## Palette

| Role | Color | Use |
|---|---|---|
| Deep graphite | `#1f4f5a` | Primary governance, audit boundary, executive surface |
| Signal teal | `#2f6f73` | ADMIT, complete packet, replay-ready state |
| Muted steel | `#5f8fa3` | Evidence, records, audit trail, platform operations |
| Warm gold | `#c9a66b` | HOLD, incomplete evidence, readiness gates |
| Refusal red | `#b94b4b` | REFUSE, critical proof missing, no audit reliance |
| Electric cyan | `#62d9ff` | Replay flow, packet linkage, verification signal |

---

## Badge System

Use badges to signal capability immediately:

```text
AI Governance
Audit Evidence Pack
Replay Ready
Proof Preservation
Executive Ready
Public Safe
```

---

## Voice

Use language that is:

- precise
- enterprise-readable
- audit-ready
- governance-forward
- architecture-oriented
- public-safe
- confident without overclaiming

Correct public claim:

```text
public-safe enterprise reference architecture and deployable pilot sandbox
```

Avoid claiming this repository is a complete production enforcement system by itself.

---

## Core Phrases

```text
Governance that cannot be proven later is only an assertion.
Preserve the decision, owner, reason, evidence, and replay path.
Audit evidence is not a log dump.
ADMIT / HOLD / REFUSE / REVALIDATE.
Show the architecture. Protect the machinery.
```
