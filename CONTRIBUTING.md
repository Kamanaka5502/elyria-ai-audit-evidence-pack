# Contributing

## Public-Safe Contributions Only

Contributions should strengthen the public-safe enterprise AI audit evidence model.

Accepted contribution types:

- documentation improvements
- public-safe evidence packet scenarios
- clearer decision logic explanations
- sandbox usability improvements
- evidence template improvements
- replay-readiness checklist improvements
- public-safe expected outcomes
- buyer or pilot-readiness templates

Do not contribute:

- credentials
- customer data
- private client artifacts
- protected Elyria Systems runtime machinery
- confidential diagrams
- proprietary implementation internals
- production logs
- regulated data

## Review Standard

A contribution should preserve the repository purpose:

```text
Prove what governance happened, what decision was made, what evidence supported it, who owned it, and whether replay can verify it later.
```

## Decision Language

Use the repository decision model consistently:

```text
ADMIT / HOLD / REFUSE / REVALIDATE
```
